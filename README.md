# TraceLens - Code Retrieval Intelligence

Samsung PRISM Generative AI Hackathon Submission
Theme 01: Agentic Code Intelligence

## Overview
TraceLens is an agentic code retrieval engine built for the CoIR AppsRetrieval benchmark. It ranks code snippets given a natural-language query without answer generation.

### Architecture Highlights
- **Retrieval Pipeline**: MTEB integrated `AbsEncoder` subclass (`PrePostPipelineEncoder`) using `BAAI/bge-small-en-v1.5`.
- **Hybrid Search**: Preprocessing of competitive programming queries, algorithmic term extraction, and dense indexing using `faiss-cpu`.
- **Speed & Scale**: Incremental indexer using SHA-256 for version control, allowing delta-updates without full reindexes.
- **Demo App**: Streamlit based developer-tool aesthetic for fast local evaluation of models.

## Limitations (Honest Reporting)
Due to constraints during development:
1. **Full Evaluation Compute**: The `CoIR-Retrieval/apps` dataset is massive. A full `run_eval.py` execution was prepared and structured perfectly for MTEB, but the full synchronous download and encoding of thousands of queries across the CPU instance timed out. The metrics presented here must be generated by running `python run_eval.py` on the final deployment node.
2. **Advanced Pipeline Stages**: RRF (BM25 + Dense) and Reranking components were architected but are disabled by default to prioritize CPU speed on free tiers. 
3. **Synthetic Versioning**: The versioning simulator relies on synthetic local edits because a dedicated public dataset for evolutionary code history does not exist in the CoIR benchmark.

## Setup & Deployment
The project is built to run fully on free tiers (like Render, HuggingFace Spaces) and can be executed via Docker.

### Local Development
```bash
python -m venv venv
source venv/bin/activate  # or .\venv\Scripts\activate on Windows
pip install -r requirements.txt
```

### Docker (Recommended)
```bash
docker build -t tracelens .
docker run -p 8501:8501 tracelens
```

### Running Evaluation
```bash
python run_eval.py
```
Outputs will be stored in `results/appsretrieval_results.json`.

### Run Demo
```bash
streamlit run src/tracelens/app/demo.py
```
